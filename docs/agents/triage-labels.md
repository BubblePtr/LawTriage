# Triage Labels

这些 skills 使用五个标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 实际使用的状态字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | maintainer 需要评估 |
| `needs-info` | `needs-info` | 等待 reporter 补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个 triage 角色时，使用上表右侧对应的状态字符串。
