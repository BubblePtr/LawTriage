# Domain Docs

本仓库使用 single-context 布局。

## 开始探索前读取

- 根目录 `CONTEXT.md`
- `docs/adr/` 下与当前任务相关的 ADR

如果这些文件不存在，静默继续。不要因为缺失而要求提前创建；相关 producer skill 会在术语或决策真正明确时再创建它们。

## 使用领域词汇

当输出 issue 标题、重构建议、诊断假设或测试名称时，优先使用 `CONTEXT.md` 中定义的领域术语。

如果需要的概念尚未出现在 `CONTEXT.md` 中，先判断是不是自己引入了项目不用的词；如果确实是领域空白，把它记录为后续补充 domain docs 的候选。

## 标出 ADR 冲突

如果输出会违反已有 ADR，明确指出冲突，而不是静默覆盖。
